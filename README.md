# 정보 수업 자료실

정보 교과 수업 소개와 학생용 학습자료를 올리는 웹사이트입니다. GitHub Pages로 무료로 띄울 수 있어요.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 사이트 화면 (고칠 필요 없음) |
| `data.js` | **사이트 내용 전부**: 공지, 학습자료, 과목 소개 |
| `files/` | 학생에게 나눠 줄 PDF, 한글, PPT, 이미지 등을 올리는 폴더 |

## 1. 처음 한 번: 사이트 띄우기

1. 저장소에 `index.html`, `data.js`, `README.md`를 올립니다 (**Add file → Upload files**).
2. 저장소 **Settings → Pages**로 갑니다.
3. **Source**를 `Deploy from a branch`, **Branch**를 `main` / `/ (root)`로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 같은 화면 위쪽에 사이트 주소(`https://아이디.github.io/저장소이름/`)가 뜹니다. 이 주소를 학생들에게 알려 주세요.

## 2. 자료 올리기

**파일 자료일 때**

1. (처음 한 번만) `files` 폴더 만들기: **Add file → Create new file** → 이름 칸에 `files/안내.txt` 입력 → 아무 글이나 쓰고 **Commit changes**
2. 저장소에서 `files` 폴더를 클릭해 들어간 다음 **Add file → Upload files**로 파일을 올립니다.
3. 저장소 첫 화면으로 돌아와 `data.js`를 열고 연필(✏️) 버튼을 눌러 `materials: [` 아래에 항목을 하나 추가합니다.

```js
    {
      title: "3차시 리스트와 반복문",
      course: "info",
      kind: "수업자료",
      unit: "알고리즘과 파이썬 프로그래밍",
      desc: "수업 전에 1~4쪽을 읽어 오세요.",
      file: "files/3차시_리스트_반복문.pdf",
      date: "2026-11-12",
      due: ""
    },
```

**링크 자료일 때**: `file:` 대신 `link: "https://..."`를 씁니다. 구글 드라이브, 클래스룸, 실습 사이트 주소 등을 넣을 수 있어요.

**과제일 때**: `kind: "과제"`, `due: "2026-11-20"`처럼 마감일을 넣으면 첫 화면 '다가오는 과제'에 D-day와 함께 표시됩니다.

4. **Commit changes**를 누르면 1~2분 뒤 사이트에 반영됩니다.

## 3. 공지 쓰기

`data.js`의 `notices: [` 아래에 추가합니다. `pinned: true`면 맨 위에 고정돼요.

```js
    {
      title: "다음 주 수행평가 안내",
      body: "11월 18일(화) 3교시에 컴퓨터실에서 진행합니다.",
      date: "2026-11-11",
      pinned: false
    },
```

## 자주 생기는 문제

- **사이트에 빨간 안내문이 뜨고 내용이 안 보여요**: `data.js`를 고치다 쉼표(`,`)나 따옴표(`"`)가 빠졌을 때 생깁니다. 마지막으로 고친 부분을 확인하세요. 항목 `{ ... }`끼리는 쉼표로 구분합니다.
- **파일 '열기'를 누르면 404가 떠요**: `file:`에 적은 이름과 실제 올린 파일 이름이 띄어쓰기·대소문자까지 똑같은지 확인하세요. 파일 이름에는 띄어쓰기 대신 `_`를 쓰는 게 안전해요.
- **고쳤는데 그대로예요**: 1~2분 기다린 뒤 새로고침(Ctrl+F5) 하세요.
- **공개 저장소이므로** 올린 파일은 주소를 아는 누구나 볼 수 있어요. 학생 개인정보가 담긴 파일은 올리지 마세요.
